# Claude book writing framework

A set of CLAUDE md files that make up a book writing framework that is used as a template for new book projects.

The CLAUDE.md will contain the highest level instructions, rules and details that will detail where to find all the framework MD files, and where all the resulting MD files (persona, writing style, book pages written by the AI)

The framework will provide MD files which will provide:

1. Writing rules and best practices
2. Writing tools and formats supported
3. Location where the resulting book MD files and where user must provide entire/partial book page drafts for the book we going to write, user page draft examples for writing persona training, documents and/or resources (containing information and/or data for the book)
4. Must describe the high level main process in steps from beginning to end and every step is a process that is described in steps as part of the main high level process
5. Persona and writing style of the author to be documented in a persona-writing-style.md file to be part of the resulting framework MD files to be read from the CLAUDE.md up.
6. Resources like images and how they should be named to be automatically included in specific page names or numbers must be prescribed by the framework for the user to take advantage of.
7. Claude SKILLS MD files for any skills included in the framework like book writing, book reviewing and book planning.

Rules:
1. Write easy to read and understand sentences and paragraphs with an emphasis on writing books for readers, mastering book writing each sentence and paragraph one at a time.
2. Write the book in MD files in standard GitHub-flavored Markdown

3. When starting a new project (greenfield project and context) then you must check that the user has provided:

   3.1 Partial/full book page drafts that currently exist of the book to be written

   3.2. Book page draft examples or writing examples written by the user to understand and match the user's writing persona and style. The resulting persona and style must be documented in the provided framework folder structure for the MD files

   3.3. Analyze persona, writing style, book page drafts and resources to determine if there are any files still needed or any clarifying questions needed that need to be finalized before moving onto writing the book chapters one chapter at a time, in one automated stretch by the agent.
