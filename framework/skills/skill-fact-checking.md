# Skill: Fact Checking

This skill helps you verify accuracy, check claims, validate sources, and ensure your book's credibility.

---

## When to Use This Skill

Use this skill when you need help with:
- Verifying claims and statements
- Checking accuracy of facts and statistics
- Validating sources and citations
- Identifying unsupported claims
- Ensuring credibility throughout book
- Checking technical accuracy

---

## What This Skill Does

### 1. Identifies Claims to Verify
- Scans chapter for factual claims
- Notes statistics and data
- Identifies sources needed
- Flags unsupported statements

### 2. Checks Accuracy
- Verifies facts are correct
- Checks statistics and data
- Confirms source quotes are accurate
- Validates technical information

### 3. Validates Sources
- Confirms sources are credible
- Verifies quotes are accurate
- Checks citations
- Identifies missing attributions

### 4. Ensures Credibility
- Flags false or misleading claims
- Identifies needed support
- Ensures proper attribution
- Maintains reader trust

## Types of Claims to Verify

### Factual Claims
- Historical facts
- Biographical information
- Technical information
- Documented events

**Examples**:
- "The internet was invented in 1969"
- "Marie Curie won two Nobel Prizes"
- "Python is a programming language"

### Statistical Claims
- Percentages and data
- Study results
- Survey findings
- Research conclusions

**Examples**:
- "78% of professionals report burnout"
- "The average person sleeps 6.8 hours"
- "Revenue increased by 45%"

### Quote Verification
- Direct quotes from people
- Book excerpts
- Famous sayings
- Attribution accuracy

**Examples**:
- Direct quotes need exact verification
- Famous quotes often misattributed
- Publication and page numbers needed
- Context matters

### Technical Accuracy
- Specialized information
- Process descriptions
- Scientific information
- Industry specifics

**Examples**:
- Medical information accuracy
- Scientific processes
- Technical procedures
- Specialized terminology

## Verification Process

### Step 1: Identify Claims
Read through chapter and note:
- Any factual statements
- Statistics or data
- Quotes or attributions
- Technical information

### Step 2: Assess Credibility Need
Determine how critical each claim is:
- Core claims need strong verification
- Supporting claims need adequate verification
- Common knowledge may not need citation
- Controversial claims need thorough verification

### Step 3: Verify Against Sources
- Consult original sources if available
- Check reliable databases or references
- Compare multiple sources for consistency
- Note any discrepancies

### Step 4: Flag Issues
Note any:
- Inaccurate statements
- Unverified claims
- Misquotes
- Missing attributions
- Questionable sources

### Step 5: Make Corrections
- Correct inaccurate claims
- Add missing citations
- Adjust phrasing if needed
- Verify corrections

## What Needs Citation

**Always cite**:
- Direct quotes
- Specific statistics or data
- Unique ideas or research
- Paraphrased information
- Specialized knowledge

**May not need citation**:
- Common knowledge (2+2=4, Earth orbits Sun)
- Well-known facts (Lincoln was 6'4")
- Your own observations
- Generally accepted ideas

**When in doubt**: Include citation

---

## Red Flags for Inaccuracy

Watch for:
- Statistics that sound too perfect
- Quotes that seem paraphrased
- Claims without source
- Information from questionable sources
- Contradictions between sources
- Outdated information
- Overgeneralizations

---

## Handling Disputed or Uncertain Information

**If information seems unsure**:
1. Consult multiple sources
2. Use qualified language: "Some research suggests..." or "Evidence indicates..."
3. Acknowledge uncertainty: "While some sources indicate..."
4. Cite credible sources
5. Consider removing if unverifiable

**Example**:
```
❌ "Exercise cures depression"
✅ "Research suggests exercise can help alleviate depression symptoms"
✅ "Studies show regular exercise is associated with improved mental health (Smith et al., 2023)"
```

---

## Citation Guidelines

**Basic format**:
- Author name
- Title or work
- Publication or source
- Date
- Optional: page numbers or URL

**Examples**:
- Smith, John. "Study Title." Journal Name, 2023.
- "Website Name." URL. Accessed: Date.
- Johnson, Jane. Personal interview. Date.

---

## Technical and Specialized Accuracy

**For technical claims**:
- Verify with subject matter experts
- Check specialized references
- Confirm terminology is correct
- Ensure processes are accurately described

**Example verification**:
```
Claim: "Python is an interpreted language"
Verification: Confirmed. Python code is interpreted at runtime.
Source: Python.org documentation
```

## Maintaining Reader Trust

**Good fact-checking**:
- Shows you're credible
- Builds reader confidence
- Demonstrates thoroughness
- Allows readers to verify further

**Poor fact-checking**:
- Undermines credibility
- Damages reader trust
- Creates liability
- Reflects poorly on author

---

## Common Accuracy Issues

**Misquotes**: Quote isn't exact
**Missing attribution**: Claim without source
**Outdated information**: Facts that have changed
**Overstated claims**: Exaggeration or misinterpretation
**Wrong source**: Attributed to wrong person
**Context missing**: Quote or fact misleading without full context
