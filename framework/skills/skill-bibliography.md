# Skill: Bibliography Management

This skill helps you organize sources, create proper citations, and compile a complete bibliography for your book.

---

## When to Use This Skill

Use this skill when you need help with:
- Organizing sources and references
- Creating proper citations
- Compiling bibliography
- Formatting citations consistently
- Tracking sources as you write
- Converting between citation styles

---

- Organizes by chapter/topic
- Tracks source information
- Manages citations

### 2. Creates Proper Citations
- Formats citations correctly
- Follows chosen style guide
- Includes all necessary information
- Handles various source types

### 3. Manages Bibliography
- Compiles complete bibliography
- Organizes alphabetically or by type
- Ensures consistency
- Formats for publication

### 4. Tracks Attribution
- Links sources to chapters
- Ensures all claims are cited

- Verifies quote attribution

## Citation Styles

### Chicago Style (Notes and Bibliography)
Used in humanities, history, literature

**Book example**:
```
Smith, John. "Book Title." Publisher, Year.

Shortened note: Smith, "Book Title," page.
```

**Website example**:
```
Website Name. "Article Title." URL. Accessed: Date.
```

### MLA Style
Used in humanities and literature

**Book**:
```
Smith, John. Book Title. Publisher, Year.
```

**Website**:
```
"Article Title." Website Name, Date Accessed, URL.
```

### APA Style
Used in social sciences and psychology

**Book**:
```
Smith, J. (Year). Book title. Publisher.
```

**Website**:
```
Website Name. (Year). Article title. Retrieved from URL
```

### Harvard Style
Similar to APA, used in UK

**Book**:
```
Smith, J. (Year) Book Title. Publisher.
```

## Source Information to Track

### For Books
- Author name(s)
- Book title
- Edition (if not first)
- Publisher
- Year of publication
- ISBN (optional)
- Pages referenced (if partial)

### For Websites
- Website name/author
- Article/page title
- URL
- Access date
- Publication date (if available)

### For Academic Papers
- Author(s)
- Paper title
- Journal name
- Volume and issue number
- Page numbers
- Publication date
- DOI (if available)

### For Interviews
- Person interviewed
- Interview date
- How conducted (in-person, email, phone, etc.)
- Your relationship (if noted)

### For Databases/Archives
- Database/archive name
- Item title
- Author (if available)
- Date (if available)
- URL or access information

## Creating Master Source List

**Format**:
```markdown
# Master Source List

## [Source Title]
- Author(s): 
- Type: [Book/Article/Website/Interview]
- Publication: 
- Date: 
- Citation: [Full citation in your style]
- Where Used: Chapters/sections where cited
- Notes: [Any notes about this source]
```

**Example**:
```markdown
## "The Study of Productivity"
- Author(s): Smith, John and Johnson, Jane
- Type: Academic Paper
- Publication: Journal of Work Science
- Date: 2023
- Citation: Smith, John, and Jane Johnson. "The Study of Productivity." 
  Journal of Work Science, 2023.
- Where Used: Chapter 3, Chapter 5
- Notes: Primary research on time management effectiveness
```

## Tracking Citations in Chapters

### Method 1: Footnotes/Endnotes
```
In Chicago style: Super script number¹

Footnote/Endnote at bottom or end:
¹ Smith, "Book Title," page X.
```

### Method 2: Parenthetical Citations
```
In MLA/APA style: (Smith 45) or (Smith, 2023)

Full citation in bibliography
```

### Method 3: Author-Date System
```
(Smith 2023) in text

Smith, John. "Title." Publisher, 2023.
```

## Common Citation Mistakes

### Missing Information
❌ Smith, "Title."
✅ Smith, John. "Title." Publisher, 2023.

### Wrong Format
❌ Smith, John; "Book Title"; Publishing House; 2023
✅ Smith, John. Book Title. Publishing House, 2023.

### Inconsistent Style
❌ Mix of Chicago, MLA, and APA in same bibliography
✅ All citations in same style

### Incomplete URLs
❌ www.example.com
✅ https://www.example.com/full/path/to/article

### Missing Access Date (for websites)
❌ Smith, John. "Article." www.example.com
✅ Smith, John. "Article." www.example.com. Accessed June 15, 2024.

## Special Citation Situations

### Translated Works
```
Original Author. Title. Translated by Translator Name. Publisher, Year.
```

### Edited Collections
```
Editor, First (ed.). Collection Title. Publisher, Year.
```

### Government/Organization Documents
```
Organization Name. Document Title. Publication, Year. URL.
```

### Personal Communications
```
Last Name, First Name. Personal communication. Date.
```

### Unpublished Manuscripts
```
Author. "Manuscript Title." Unpublished manuscript, Date.
```
