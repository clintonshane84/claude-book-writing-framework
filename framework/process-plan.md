# Phase 1: Planning Process

The Planning phase establishes the foundation for your book writing project. In this phase, you will define the book's structure, create chapter outlines, establish writing targets, and prepare for the writing work ahead.

**Duration**: Usually 1-3 days depending on book complexity

**Outcome**: A complete outline with chapter summaries, writing targets, and clear direction for Phase 2 (Writing)

---

## Phase 1 Overview

The Planning phase consists of these steps:

1. **Define Book Structure** - Overall organization and chapter count
2. **Create Detailed Outline** - Chapter-by-chapter breakdown
3. **Establish Writing Targets** - Goals for chapters, length, and timeline
4. **Prepare for Writing** - Set up writing process and schedule

---

## Step 1: Define Book Structure

### 1.1 Confirm Book Scope
Start by confirming the book's scope is clear:

- **Topic/Story**: What is this book fundamentally about?
- **Target Audience**: Who will read this?
- **Purpose**: What should readers gain or learn?
- **Length**: How long? (approximate page count or chapter count)

**Deliverable**: A 2-3 sentence summary of the book's scope

Example:
```
"This book teaches parents evidence-based strategies for navigating 
the teenage years. It combines research with practical advice and 
real-world examples. Target audience: parents of teens 13-18. 
Length: 12-15 chapters, approximately 200-250 pages."
```

### 1.2 Determine Chapter Count
Estimate how many chapters your book will have:

- **Short book**: 5-8 chapters
- **Standard book**: 10-15 chapters
- **Comprehensive book**: 15-25+ chapters

Consider:
- How many major topics or sections?
- Should chapters be focused (narrow scope) or broader?
- Is there a natural chapter arc or progression?

**Deliverable**: Preliminary chapter count (can adjust as you write)

### 1.3 Plan Chapter Progression
Map out the general flow from beginning to end:

Example progression:
```
Introduction → Core Concepts → Application → Advanced Topics → Conclusion
```

Or for narrative:
```
Setup → Inciting Incident → Rising Action → Climax → Resolution
```

**Deliverable**: High-level flow/progression outline

---

## Step 2: Create Detailed Outline

### 2.1 Chapter-by-Chapter Outline
For each chapter, create a brief outline:

**Format**:
```
## Chapter 1: Title
- Introduce main concept
- Provide example/story
- Explain implications
- Bridge to next chapter

## Chapter 2: Title
- Build on previous chapter
- Introduce new concept
- Provide case study
- Foreshadow Chapter 3
```

**Level of detail**: Each chapter should have 3-5 main points or sections

### 2.2 Section Planning
For longer chapters, plan sections within chapters:

```
## Chapter 3: Advanced Strategies

### Section 3.1: Strategy A
- Overview of Strategy A
- How to implement
- Common mistakes
- Example

### Section 3.2: Strategy B
- Overview of Strategy B
- How to implement
- Common mistakes
- Example

### Section 3.3: Combining Strategies
- When to use together
- Examples of combined approach
```

### 2.3 Research and Reference Planning
For each chapter, identify:
- **Key concepts** that need to be explained
- **Examples or stories** you'll include
- **Research or data** to reference
- **Resources** you'll need (images, diagrams, data)

**Deliverable**: Detailed outline document (markdown file in repository root or `/resources/outline/`)

---

## Step 3: Establish Writing Targets

### 3.1 Chapter Length Targets
Decide on ideal chapter length:

**Common approaches**:
- Consistent length: Each chapter ~3,000-5,000 words
- Variable length: Introductory chapters shorter, core chapters longer
- By content: Chapter length determined by topic complexity

Set targets for each chapter or chapter group:
```
Chapters 1-2: 2,500-3,000 words (intro)
Chapters 3-7: 4,000-5,000 words (core content)
Chapters 8-9: 3,500-4,000 words (application)
Chapter 10: 2,000-2,500 words (conclusion)
```

### 3.2 Writing Timeline
Plan when chapters will be written:

**Options**:
- **Sequential**: Write Chapter 1, then 2, then 3, etc. (most common)
- **Themed**: Write all intro chapters, then all core chapters, etc.
- **Priority**: Write most important chapters first, easier chapters later

**Example timeline**:
```
Week 1: Chapters 1-2 (intro)
Week 2: Chapters 3-4 (core)
Week 3: Chapters 5-6 (core)
Week 4: Chapters 7-8 (application)
Week 5: Chapters 9-10 (conclusion and review)
Week 6: Revisions and polish
```

### 3.3 Quality Targets
Define what "done" means for each chapter:

- [ ] **Draft complete**: All main points written in rough form
- [ ] **Structured**: Sections organized logically, flows well
- [ ] **Detailed**: Examples added, explanations clear
- [ ] **Persona-consistent**: Matches established writing voice
- [ ] **Reviewed**: Checked for clarity and consistency
- [ ] **Polished**: Grammar corrected, final edits made

**Deliverable**: Writing targets document with timeline and quality criteria

---

## Step 4: Prepare for Writing

### 4.1 Set Up Writing Environment

**Repository structure ready**:
- [ ] `/framework/` folder with all framework files
- [ ] `/book/` folder ready for chapters
- [ ] Chapter folders created for first few chapters (e.g., `/book/01-intro/`)
- [ ] Each chapter folder has:
  - [ ] `chapter.md` (empty, ready for content)
  - [ ] `drafts/` folder
  - [ ] `resources/` folder

### 4.2 Prepare Resources
Gather and organize resources needed for writing:

**To prepare**:
- [ ] Research materials organized
- [ ] Images/diagrams identified or created
- [ ] Data and statistics collected
- [ ] Quotes or excerpts compiled
- [ ] Writing samples in resources folder

**To reference**:
- [ ] persona-writing-style.md reviewed and finalized
- [ ] writing-rules.md bookmarked
- [ ] writing-tools.md reviewed for markdown reference

### 4.3 Create Writing Checklist
For each chapter, prepare a personalized writing checklist:

**Example chapter writing checklist**:
```markdown
# Chapter X: Title - Writing Checklist

## Preparation
- [ ] Read chapter outline
- [ ] Review related writing samples
- [ ] Gather research/resources for this chapter
- [ ] Check persona-writing-style.md for voice reminders

## Writing
- [ ] Draft all main sections
- [ ] Add examples and illustrations
- [ ] Include any data or statistics
- [ ] Connect to surrounding chapters
- [ ] Write opening and closing sections

## Review (Self)
- [ ] Read through for clarity
- [ ] Check paragraph structure
- [ ] Verify voice matches persona
- [ ] Fix obvious errors
- [ ] Ensure section flow is logical

## Polish
- [ ] Proofread for grammar and spelling
- [ ] Check formatting (headers, emphasis, lists)
- [ ] Verify image references and alt text
- [ ] Final read-through
- [ ] Commit to chapter.md

## Next Step
- [ ] Move to Chapter X+1 or Review phase
```

### 4.4 Establish Writing Discipline
Set writing practices:

**Suggested practices**:
- **Writing schedule**: Daily, or specific days/times
- **Session structure**: How long will writing sessions be?
- **Daily target**: Words per day, or sections per day?
- **Revision approach**: Revise immediately after writing, or save for later?
- **Feedback cadence**: How often get feedback? After each chapter?

**Example schedule**:
```
- Write daily: 1-2 hours in morning
- Target: 1,000-1,500 words per day
- Sessions: Monday-Friday
- Weekend: Review and revise previous week's work
- Commit to git: End of each day
```

---

## Step 5: Confirm Plan with Author

### 5.1 Review and Approve
Present the completed plan:

**Walkthrough**:
1. Review book scope and structure
2. Walk through chapter-by-chapter outline
3. Review writing targets and timeline
4. Discuss any concerns or adjustments

### 5.2 Make Adjustments
If author wants changes:
- Adjust chapter count or scope
- Reorder chapters or topics
- Change timeline or targets
- Modify quality criteria

### 5.3 Gain Approval
Get explicit approval before moving to Phase 2:

```
Plan Confirmation Checklist:
- [ ] Author approves overall structure
- [ ] Author approves chapter outline
- [ ] Author agrees with timeline
- [ ] Author confirms writing targets
- [ ] Author is ready to begin Phase 2 (Writing)
```

---

## Deliverables for Phase 1

By the end of Planning, you should have:

1. **Book Structure Document**
   - Topic, audience, purpose summary
   - Chapter count and progression
   - Overall arc/flow

2. **Detailed Chapter Outline**
   - All chapters listed with titles
   - Main points/sections for each chapter
   - Research and resources identified

3. **Writing Targets**
   - Timeline (when each chapter will be written)
   - Length targets per chapter
   - Quality criteria and completion checklist
   - Writing discipline/schedule

4. **Repository Setup**
   - Framework files in place
   - Chapter folders created
   - Resources organized

5. **Writing Resources**
   - Persona-writing-style.md finalized
   - Research materials organized
   - Writing samples in resources

6. **Author Approval**
   - Plan reviewed and approved
   - Any adjustments made
   - Ready to proceed to Phase 2

---

## Common Planning Mistakes to Avoid

- ❌ **Over-planning**: Don't create massive detailed outlines; 3-5 bullet points per chapter is enough
- ❌ **Uncertain scope**: Make sure book topic and audience are crystal clear
- ❌ **Unrealistic timelines**: A chapter takes time; don't plan for a book in two weeks
- ❌ **Ignoring persona**: Don't plan content that contradicts established writing voice
- ❌ **Skipping resources**: Gather research and materials before writing, not during
- ❌ **No iteration allowed**: Build flexibility into timeline for revisions

---

## Signs Plan is Complete

✅ **Plan is complete when**:
- Book structure is clear and approved
- All chapters have outline/summary
- Writing timeline is realistic
- Chapter folders are set up
- Resources are gathered
- Author has approved plan
- You're ready to write Chapter 1

✅ **Not ready to move forward if**:
- Scope is still unclear
- Chapters don't flow logically
- Timeline is unrealistic
- Resources are missing or unclear
- Author hasn't approved
