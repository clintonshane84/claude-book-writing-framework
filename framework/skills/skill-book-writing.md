# Skill: Book Writing

This skill helps you draft chapters, develop ideas, and maintain your writing voice throughout the book.

---

## When to Use This Skill

Use this skill when you need help with:
- Drafting chapters from outline
- Developing ideas and content
- Creating examples and illustrations
- Maintaining consistent voice and style
- Overcoming writer's block
- Improving paragraph and sentence flow
- Writing openings and closings

---

## What This Skill Does

### 1. Drafts Chapters
- Transforms outline into actual chapter content
- Develops main points with detail and examples
- Writes opening hooks and closing summaries
- Maintains appropriate length and pacing

### 2. Develops Ideas
- Expands brief outline points into full sections
- Creates specific examples and stories
- Adds supporting details and illustrations
- Connects ideas logically

### 3. Maintains Consistency
- Writes in your established persona and voice
- Uses consistent terminology
- References previous chapters appropriately
- Bridges between chapters effectively

### 4. Solves Writing Challenges
- Helps overcome stuck sections
- Finds better ways to express ideas
- Strengthens weak paragraphs
- Improves overall flow and readability

### 5. Uses Global Resources
- Automatically incorporates materials from `/inputs/` folder
- Integrates draft pages and research into chapters
- References examples and style guidance
- Ensures consistency with provided materials

---

## Using Global Resources from `/inputs/`

This skill automatically uses materials from your `/inputs/` folder when writing chapters.

### What Gets Included

**Draft Pages** (`/inputs/draft-pages/`):
- Partially written chapters or sections
- Your existing openings or key passages
- Outlines and notes you've prepared
- Previous attempts you want to build on

**Research** (`/inputs/research/`):
- Studies and academic findings
- Interview transcripts and expert quotes
- Statistics and data
- Case studies and examples

**References** (`/inputs/references/`):
- Writing style examples to match
- Chapter structure examples
- Technical terminology definitions
- Inspirational passages and quotes

### How It Works

When you ask me to write a chapter:

1. **Automatic Context**: I read all `/inputs/` files
2. **Seamless Integration**: Research and drafts inform writing naturally
3. **Smart Reference**: I know which materials apply to which chapters
4. **Voice Consistency**: I match the examples you've provided
5. **Content Continuity**: Partial drafts guide completion

**You don't need to reference these files explicitly**—I automatically consider them.

### Before Writing a Chapter

Ensure `/inputs/` is organized with:
- [ ] Relevant draft pages (if any)
- [ ] Research for this chapter topic
- [ ] Reference materials showing desired style
- [ ] Any global resources that apply

- Any specific examples or data to include

## Writing Process

### Before Writing
1. Review chapter outline
2. Review persona-writing-style.md
3. Read previous chapter for continuity
4. **Review relevant materials in `/inputs/`** (research, drafts, references)
5. Gather research/examples for this chapter
6. Consider target length and audience

### During Writing
1. Start with opening hook
2. Develop main points in order
3. Include specific examples
4. Use transitions between sections
5. Close with summary and bridge

### After Writing
1. Read through for flow
2. Check against outline (all points covered?)
3. Verify voice matches persona
4. Fix obvious unclear sections
5. Commit to git when satisfied

## Writing Tips from This Skill

**For Strong Openings**:
- Start with a question, story, or interesting statement
- Introduce the chapter topic clearly
- Hook the reader's interest
- Bridge from previous chapter if appropriate

**For Clear Development**:
- One idea per paragraph
- Support with specific examples
- Use transitions between ideas
- Show, don't just tell

**For Effective Closings**:
- Summarize key points
- Emphasize what readers should take away
- Bridge to next chapter (if applicable)
- End on a memorable note

**For Maintaining Voice**:
- Refer to persona-writing-style.md frequently
- Match sentence length and structure of previous chapters
- Use characteristic vocabulary and phrasing
- Keep authentic, genuine tone

## Common Writing Challenges

**Stuck on a section?**
- Skip it, write the rest, come back to it
- Try explaining it differently
- Add an example to make it clearer
- Break it into smaller pieces

**Section too short?**
- Add specific examples
- Explain implications
- Include relevant details
- Develop the idea more fully

**Section too long?**
- Is it all necessary?
- Can any points be condensed?
- Should it move to next chapter?
- Can you remove redundancy?

**Voice sounds off?**
- Read persona-writing-style.md
- Reread previous chapter opening
- Identify what's different
- Adjust phrasing and tone

**Lost the thread?**
- Reread chapter outline
- Remember chapter purpose
- Reconnect to main idea
- Refocus remaining content

## Draft Organization

**Keep drafts organized**:
- Primary draft in `chapter.md`
- Save backup to `drafts/draft-v1.md` when complete
- If major revision needed, save to `drafts/draft-v2.md`
- Final version stays in `chapter.md`

**Commit frequently**:
- After initial draft: "Draft chapter X"
- After revisions: "Revise chapter X"
- After final review: "Complete chapter X"
